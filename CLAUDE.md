# CLAUDE.md — Планировщик (Telegram Mini App)

## О проекте
- Личный планировщик владельца в виде Telegram Mini App. Полное ТЗ владелец прислал в чате; разработка по этапам, после каждого этапа — остановка и проверка владельцем в Telegram (телефон + ноутбук).
- Владелец — новичок: объяснять простыми словами, говорить, что нажать и что проверить.
- Версия 1 — бесплатно: без сервера, без платных подписок, без Claude API.
- Токен бота НИКОГДА не попадает в код и в репозиторий.

1. Каркас: вкладки, тема Telegram, хранение, резервная копия, GitHub Pages + бот — **принят владельцем (8.11.2026)**. Сайт: https://paramonovanastja-lab.github.io/planner/ (аккаунт GitHub paramonovanastja-lab). Файлы владелец загружает через сайт GitHub (Add file → Upload files), не через GitHub Desktop.

7. Помодоро, вибрация, настройки, финальная проверка.

## Устройство
- Всё в одном `index.html` (HTML + CSS + JS), библиотека `telegram-web-app.js`. Без сборщиков и сервера. Хостинг — GitHub Pages.
- Цвета — только переменные `--bg --bg2 --card --text --hint --link --btn --btn-text --sep --danger` (берутся из `--tg-theme-*`, вне Telegram — свои светлые/тёмные).
- Данные — только через `Store` (`get`, `set(key, value | null)`, `keys(prefix)`); `set` сразу пишет на устройство, в облако — через 1 с. Подписка на обновления из облака — `Store.on`.
- Ключи облака: только `A-Z a-z 0-9 _ -` (двоеточие нельзя): `day_YYYY-MM-DD`, `hm_YYYY-MM`, `habits`, `recur`, `ideas`, `settings`, `check` (заметка для проверки синхронизации, этап 1). Длинные значения сами делятся на части `ключ__N` (заголовок `#parts:N`).
- Сверка: что ещё не ушло в облако (`dirty`) и новее облака — отправляется; остальное берётся из облака; ключ, которого нет в облаке и он не «грязный», — удалён на другом устройстве.
- Повторы `recur`: `{ items:[{id,text,time?,days:[0–6, пн=0],from,until?}] }` — `getRecur` / `saveRecur` / `rulesFor(iso)`; «удалить» повтор = `until` на день раньше (прошлые дни сохраняются). Отметка повтора в дне — `rdone[id]`. Дедлайн — только у разовых задач; в календаре красная точка = невыполненный дедлайн. Синяя точка — только свои задачи и планы дня (повторы не считаются, иначе точки были бы везде).
- Окно задачи — экран `task` (`openTask(iso, id, rid, text)`), поиск — экран `search` (ищет только в дневнике).
- День `day_YYYY-MM-DD`: `{ tasks:[{id,text,done,time?,deadline?}], rdone:{}, plan:{"09:30":"текст"}, diary:"", mood:0–5 }`; читать через `getDay(iso)`, писать через `saveDay(iso, d)` (пустой день удаляет ячейку). Шкала времени берёт `settings.dayStart` / `dayEnd` (часы) / `step` (мин), по умолчанию 7 / 23 / 30.
- Навигация: вкладки `nav.tab`, экраны поверх — `openScreen(name)` / `back()`; кнопка «Назад» Telegram подключена к `back()`.
- Проверка без Telegram: копия страницы с поддельным `window.Telegram.WebApp` (облако в localStorage) — тестовые файлы держать вне репозитория.
- Новые поля ввода — `font-size: 16px` (иначе iPhone приближает страницу), `spellcheck="false" autocorrect="off"`.
